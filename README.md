# Bloomify

## Run it on your computer
1. Install Node.js (LTS version) from https://nodejs.org and restart your computer.
2. Unzip this folder, open a terminal inside it.
3. Run `npm install` (once), then `npm run dev`.
4. Open the link it shows (usually http://localhost:5173).

## Change things
- Text, colours and reviews: `src/App.jsx` (the sample reviews are at the top).
- Photos: `public/flowers/`.
- Publish: `npm run build`, then upload the `dist` folder to Netlify or Vercel.
